# React + Vite Pet Project

This is a simple **React** application bootstrapped with **Vite**. The project is set up to use **React** for building the UI with fast development and live-reloading features powered by **Vite**.

## Project Setup

To get started with this project, you'll need **Node.js** (version 14 or higher) installed on your machine.

1. **Clone the repository**:

   git clone <repository-url>
   cd <project-directory>

   1. **Install dependencies:**:

   npm install

## Available Scripts

In the project directory, you can run:

npm run dev — Starts the development server and opens the app in your browser.

npm run build — Builds the app for production to the /dist folder.

npm run preview — Previews the production build locally.

## Technologies Used

React — JavaScript library for building user interfaces.

Vite — A next-generation, fast development build tool.

CSS Modules — Scoped CSS for styling React components.

ESLint — JavaScript linting for code quality.

## Project Structure

/public

index.html: The HTML template file.

/src

/assets: Images, icons, etc.

/components: Reusable React components.

/pages: React pages (views).

App.jsx: Main app component.

index.js: Entry point for React app.

/styles: Global styles (if applicable).

.gitignore: Specifies which files and directories Git should ignore.

package.json: Project metadata and dependencies.

vite.config.js: Vite configuration file.
